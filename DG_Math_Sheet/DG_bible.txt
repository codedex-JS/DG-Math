Hitboxes:
Example: Ray vs. Circle Hitbox
Setup:
    Enemy hitbox: circle at position (150, 200) with radius 30
    Player’s sword swing: ray starting at (80, 180), direction (0.8, 0.6), length 120
Python code:
______________________________________________________________________________
# 1. Define vectors and scalars
enemy_center = (150, 200)
enemy_radius = 30

sword_origin = (80, 180)
sword_dir = (0.8, 0.6)      # already normalized (length = 1)
sword_length = 120

# 2. Vector from sword start to enemy center
to_center = (enemy_center[0] - sword_origin[0],
             enemy_center[1] - sword_origin[1])   # = (70, 20)

# 3. Project that vector onto sword direction using dot product
t = (to_center[0] x sword_dir[0] + to_center[1] x sword_dir[1])  # = 70x0.8 + 20x0.6 = 68

# 4. Clamp t to the sword’s length (0 to 120)
t_clamped = max(0, min(t, sword_length))  # = 68

# 5. Find the closest point on the ray segment
closest_point = (sword_origin[0] + sword_dir[0] x t_clamped,
                 sword_origin[1] + sword_dir[1] x t_clamped)   # = (80+54.4, 180+40.8) = (134.4, 220.8)

# 6. Vector from closest point to enemy center
to_center_from_closest = (enemy_center[0] - closest_point[0],
                          enemy_center[1] - closest_point[1])   # = (15.6, -20.8)

# 7. Check distance against radius
distance = (to_center_from_closest[0]xx2 + to_center_from_closest[1]xx2) xx 0.5   # ≈ 26.0

if distance < enemy_radius:
    print("HIT!")   # 26.0 < 30 → true
else:
    print("Miss")
______________________________________________________________________________
Because 26.0 < 30, the sword hits the enemy.
The key vector operations are subtraction (to get offsets), dot product (to project), and length (to measure distance). This same math powers bullet traces, melee attacks, and line‑of‑sight checks.
